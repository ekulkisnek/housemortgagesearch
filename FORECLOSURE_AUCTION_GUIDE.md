# 🏠 Free Foreclosure Auction Finder

## Get Real Foreclosure Auctions with Prices - 100% FREE

This tool scrapes **real foreclosure auction listings** from **free public sources** and shows you properties sorted by **lowest prices**.

---

## 🚀 Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

Or manually:
```bash
pip install requests beautifulsoup4 lxml
```

### 2. Run the Scraper

```bash
python get_foreclosure_auctions.py
```

This will:
- ✅ Scrape ILFLS free daily auction lists
- ✅ Get real property addresses
- ✅ Extract case numbers and prices
- ✅ Sort by lowest price
- ✅ Save results to JSON file

---

## 📋 What You Get

The script searches these **FREE** sources:

### 1. **ILFLS (Illinois Foreclosure Listing Service)** ⭐ PRIMARY SOURCE
- **URL**: https://ilfls.com/free-daily-auction-lists/
- **FREE daily foreclosure auction lists**
- Includes addresses, case numbers, prices, auction dates
- Available for: DuPage, Cook, Lake, Will, Kane counties

### 2. **HUD Home Store**
- **URL**: https://www.hudhomestore.com
- Federal foreclosure listings
- Free access

### 3. **County Sheriff Offices**
- DuPage: (630) 682-7256
- Cook: (312) 603-5113
- Free public records

### 4. **Other Free Sources**
- ForeclosureListingsUSA.com
- HousingAuctions.net

## 🛠️ Troubleshooting

### If no properties are found:

1. **Check internet connection**
2. **Visit ILFLS directly** - Website structure may have changed
3. **Try different counties** - Some may have no active auctions
4. **Contact county offices** - They have the most current data

### If you get import errors:

```bash
pip install --upgrade requests beautifulsoup4 lxml
```

### If scraping is blocked:

- ILFLS website may have changed structure
- Use direct links provided above
- Contact county offices for current listings
