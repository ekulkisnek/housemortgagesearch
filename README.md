# Foreclosure Auction Finder - FREE Public Data Sources

Find **real foreclosure auction listings** with **actual prices** from **100% FREE public sources**. No paid subscriptions required!

## 🚀 Quick Start

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Foreclosure Finder

```bash
python get_foreclosure_auctions.py
```

This will:
- ✅ Scrape ILFLS free daily auction lists for multiple Illinois counties
- ✅ Get real property addresses (not autogenerated)
- ✅ Extract case numbers, prices, and auction dates
- ✅ Sort properties by lowest price
- ✅ Save results to `foreclosure_auctions.json`

## 📋 What You Get

### Free Data Sources:

1. **ILFLS (Illinois Foreclosure Listing Service)** ⭐ PRIMARY SOURCE
   - https://ilfls.com/free-daily-auction-lists/
   - FREE daily foreclosure auction lists
   - Includes addresses, case numbers, prices, auction dates

2. **HUD Home Store**
   - https://www.hudhomestore.com
   - Federal foreclosure listings

3. **County Sheriff Offices**
   - DuPage: (630) 682-7256
   - Cook: (312) 603-5113
   - Free public records
